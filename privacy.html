agenda-bot 개인정보처리방침

시행일 2026-11-12

1. 이용자

agenda-bot은 운영자 한 사람만 사용하는 개인용 도구입니다. 운영자 본인의 Google 계정으로만 로그인하며, 다른 사람에게 제공하지 않습니다.

2. 접근하는 Google 사용자 데이터

  • Gmail: 운영자 본인 계정의 메일을 읽기 전용(gmail.readonly)으로 읽습니다. 메일을 보내거나, 지우거나, 바꾸지 않습니다.
  • Google Drive와 Google 시트: 운영자가 지정한 폴더의 파일을 읽고, 수집한 원문 사본과 안건 목록 시트를 운영자 본인의 Drive에 저장합니다.

3. 사용 목적

가져온 데이터는 운영자에게 요청 사항, 기한, 후속 조치를 정리해 알려 주는 데에만 씁니다. 광고, 판매, 프로필 작성, 신용 평가에는 쓰지 않습니다.

4. 저장 위치

데이터는 운영자가 관리하는 비공개 서버와 운영자 본인의 Google Drive에만 저장됩니다. 서버 접근 권한은 운영자에게만 있습니다.

5. 제3자 처리

안건을 분류하고 요약하기 위해, 메일과 문서 내용의 일부를 운영자 본인이 구독한 AI 서비스(OpenAI, Anthropic)로 보내 처리할 수 있습니다. 이 처리는 운영자에게 정리 결과를 보여 주는 데에만 쓰이며, 그 밖의 제3자에게 데이터를 판매하거나 공유하지 않습니다.

6. Google API 서비스 사용자 데이터 정책 준수

agenda-bot이 Google API로부터 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 제한적 사용(Limited Use) 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

agenda-bot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. 보관과 삭제

운영자는 필요 없어진 원문을 정해진 기한이 지나면 지우고 요약만 남깁니다. Google 계정 설정의 "타사 앱 및 서비스"에서 언제든 agenda-bot의 접근 권한을 해제할 수 있으며, 해제하면 더 이상 데이터를 가져오지 않습니다.

8. 변경

이 방침이 바뀌면 이 페이지를 고치고 시행일을 갱신합니다.
